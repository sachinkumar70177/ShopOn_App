# ShopOn — E-Commerce Web Application

ShopOn is a frontend e-commerce web application that provides users with an online shopping experience, including product browsing, filtering, authentication, cart management, and checkout/payment flow.

The project is built using **HTML, CSS, JavaScript, and JSON Server**.

## 🚀 Features

- 🛍️ Product listing and browsing
- 🔍 Product search
- 📂 Product category filtering
- 💰 Product sorting by price
- 📄 Product details page
- 🛒 Shopping cart
- 👤 User login and signup
- 🔐 OTP verification
- 💳 Payment page
- ❤️ Wishlist
- ❓ Help section
- 📧 Newsletter section
- 📱 Responsive user interface
- 🌐 JSON Server for product/data management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON Server
